# Test plan: projects

## projects.go

| ID | Function | Scenario Type | Scenario | Precondition | Expected Result | Priority | Notes |
|----|----------|---------------|----------|---------------|------------------|----------|-------|
| PJ-01 | getReleases | Happy Path | Token set, GitHub responds 200 with a valid JSON release array | `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped for a RoundTripper returning a 200 response whose body is a valid `[]Release` JSON array | Returns the decoded `[]Release` slice matching the fixture, `nil` error | P1 |  |
| PJ-03 | getReleases | Error Path | `http.NewRequest` fails because the configured `APIEndpoint` is not a valid URL (`http://bad host`) | `cfg.GitHub.Token` non-empty; `cfg.GitHub.APIEndpoint = "http://bad host"`; no transport swap needed since the request is never sent | Returns `nil` and a non-nil error (URL parse/`net/url` error), and no network call occurs | P2 |  |
| PJ-04 | getReleases | Error Path | `client.Do` fails at the transport level | `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped for a RoundTripper returning a canned error | Returns `nil` and an error equal to (wrapping) the canned transport error | P2 |  |
| PJ-05 | getReleases | Error Path | GitHub responds 200 but body is not valid JSON | `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped for a RoundTripper returning a 200 response with body `"not json"` | Returns `nil` and a non-nil JSON decode error | P2 |  |
| PJ-06 | getReleases | Edge Case | GitHub responds 200 with an empty JSON array `[]` | `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped for a RoundTripper returning a 200 response with body `"[]"` | Returns a non-nil, zero-length `[]Release` slice and `nil` error | P3 |  |
| PJ-16 | getReleases | Happy Path | the caller's ctx reaches the outbound GitHub request | `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped for a RoundTripper that records the request; ctx carries a marker value | The recorded request's `Context()` holds the marker value, `nil` error | P1 | |
| PJ-17 | getReleases | Error Path | GitHub answers 404 | transport returns 404 | Returns `nil`, `ErrReleasesNotFound` | P1 |  |
| PJ-18 | getReleases | Error Path | GitHub answers 403 or 429 | transport returns 403, then 429 | Returns `nil`, `ErrGitHubRateLimited` for each | P1 |  |
| PJ-19 | getReleases | Error Path | GitHub answers any other non-200 status | transport returns 500, then 401 | Returns `nil`, `ErrGitHubStatus` for each | P1 |  |
| PJ-20 | getReleases | Edge Case | Group and project contain URL-special characters | group `a/../b`, project `p q`; transport records the request | The request path is `/repos/a%2F..%2Fb/p%20q/releases`; nil error | P1 |  |
| PJ-07 | ConvertToFMLFormat | Happy Path | Single release with a well-formed `"vX.Y"`-style tag | `releases = []Release{{TagName: "v1.20.1", URL: "https://example/1"}}` | Returned map has `homepage` equal to input URL, `promos["<version>-latest"]` and `["<version>-recommended"]` equal to `releases[0].URL` for every entry in `forgeModVersions`, and every `forgeModVersions` key maps to `map[string]string{"1.20.1": "https://example/1"}` | P1 |  |
| PJ-08 | ConvertToFMLFormat | Edge Case | Multiple releases with distinct tags | `releases` holds two releases, e.g. `v1.20.1` and `v1.19.4`, each with its own URL | The combined `releaseMap` (containing both version→URL entries) is assigned identically under every `forgeModVersions` key in the result (the function does not filter per compatible version), and `promos` entries all point at `releases[0].URL` | P2 |  |
| PJ-09 | ConvertToFMLFormat | Edge Case | empty releases slice | `releases = []Release{}` | Does not panic; `homepage` set, `promos` empty, and every `forgeModVersions` key maps to an empty map | P2 | |
| PJ-10 | ConvertToFMLFormat | Error Path | release tag missing a "v" prefix | `releases = []Release{{TagName: "1.20.1", URL: "https://example/1"}}` | Does not panic; the tag is used as-is, so every `forgeModVersions` key maps to `map[string]string{"1.20.1": "https://example/1"}` | P2 | |
| PJ-11 | GetReleasesHandler | Happy Path | Request with no `format` query param, upstream succeeds | Path values `group`/`project` set; `cfg.GitHub.Token` non-empty; `http.DefaultTransport` swapped to return a valid release array | 200 status, `Content-Type: application/json`, body is the JSON-encoded `[]Release` from `getReleases` | P1 |  |
| PJ-12 | GetReleasesHandler | Happy Path | Request with `format=fml`, upstream succeeds with one well-formed release | Path values `group`/`project` set; `?format=fml`; `cfg.GitHub.Token` non-empty; transport swapped to return one release with a `"vX.Y"` tag | 200 status, `Content-Type: application/json`, body is the JSON-encoded map from `ConvertToFMLFormat` (contains `homepage`, `promos`, and per-version keys) | P1 |  |
| PJ-14 | GetReleasesHandler | Edge Case | Request with `format=fml`, upstream returns an empty release array | Path values `group`/`project` set; `?format=fml`; `cfg.GitHub.Token` non-empty; transport swapped to return `[]` | 200 status, body is the JSON-encoded map with `homepage` set and an empty `promos` object | P2 | |
| PJ-15 | GetReleasesHandler | Error Path | `getReleases` fails | `cfg.GitHub.Token` non-empty; transport returns `testutil.ErrTransportFailed` | 500 status, body is `msgFailedToGetReleases` followed by a newline; no cause text | P2 | |
| PJ-21 | GetReleasesHandler | Error Path | GitHub answers 404 | transport returns 404 | 404 status, body is `msgReleasesNotFound` followed by a newline | P1 |  |
| PJ-22 | GetReleasesHandler | Error Path | GitHub answers 403 | transport returns 403 | 503 status, body is `msgGitHubRateLimited` followed by a newline | P1 |  |
| PJ-23 | GetReleasesHandler | Error Path | GitHub answers 500 | transport returns 500 | 502 status, body is `msgGitHubBadStatus` followed by a newline | P1 |  |
